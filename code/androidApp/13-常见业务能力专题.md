# 13 常见业务能力专题：登录、推送、WebView、分享、支付、地图、蓝牙、音视频

> 业务专题不需要一开始全学完，但它们是实际项目最常见的能力。每个专题都建议从 App API、系统限制、第三方 SDK、权限和异常恢复几个角度看。

---

## 1. 登录态和 Token 刷新

典型结构：

```text
LoginRepository
  -> TokenStore(DataStore/Encrypted storage)
  -> AuthInterceptor
  -> TokenAuthenticator
```

Authenticator 处理 401：

```kotlin
class TokenAuthenticator(
    private val tokenRepository: TokenRepository,
) : Authenticator {
    override fun authenticate(route: Route?, response: Response): Request? {
        if (responseCount(response) >= 2) return null
        val token = tokenRepository.refreshBlocking() ?: return null
        return response.request.newBuilder()
            .header("Authorization", "Bearer $token")
            .build()
    }
}
```

重点：并发刷新要加锁，刷新失败要统一退出登录。

## 2. 推送通知

流程：

```text
服务端 -> FCM/厂商通道 -> App MessagingService -> 通知/同步任务
```

```kotlin
class MessagingService : FirebaseMessagingService() {
    override fun onMessageReceived(message: RemoteMessage) {
        if (message.data["type"] == "sync") {
            WorkManager.getInstance(this).enqueue(OneTimeWorkRequest.from(SyncWorker::class.java))
        }
    }

    override fun onNewToken(token: String) {
        tokenRepository.updatePushToken(token)
    }
}
```

注意通知权限、channel、后台限制和厂商通道差异。

## 3. WebView 和 H5 混合

```kotlin
webView.settings.javaScriptEnabled = true
webView.webViewClient = object : WebViewClient() {
    override fun shouldOverrideUrlLoading(view: WebView, request: WebResourceRequest): Boolean {
        return request.url.host !in trustedHosts
    }
}

webView.addJavascriptInterface(Bridge(), "AndroidBridge")
```

JS Bridge 风险很高：

- 只暴露必要方法。
- 校验调用来源。
- 参数做严格解析。
- 不把 token 暴露给任意页面。

## 4. 分享和 FileProvider

manifest：

```xml
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>
```

分享：

```kotlin
val uri = FileProvider.getUriForFile(context, "${BuildConfig.APPLICATION_ID}.fileprovider", file)
val intent = Intent(Intent.ACTION_SEND).apply {
    type = "image/jpeg"
    putExtra(Intent.EXTRA_STREAM, uri)
    addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
}
startActivity(Intent.createChooser(intent, null))
```

## 5. 支付

支付关注点：

- 订单创建必须由服务端完成。
- 客户端只拉起支付 SDK。
- 支付结果以服务端回调为准。
- App 侧结果只用于 UI 提示和主动查询。

```kotlin
viewModelScope.launch {
    val order = orderRepository.createOrder(cartId)
    val result = paymentClient.pay(order.paymentParams)
    orderRepository.refreshOrder(order.id)
}
```

不要相信客户端本地支付成功状态。

## 6. 地图和定位

定位权限：

- 前台定位。
- 后台定位。
- 精确/模糊定位。

Flow 适配定位：

```kotlin
fun FusedLocationProviderClient.locationUpdates(request: LocationRequest): Flow<Location> = callbackFlow {
    val callback = object : LocationCallback() {
        override fun onLocationResult(result: LocationResult) {
            result.lastLocation?.let { trySend(it) }
        }
    }
    requestLocationUpdates(request, callback, Looper.getMainLooper())
    awaitClose { removeLocationUpdates(callback) }
}
```

后台持续定位通常需要前台服务。

## 7. 蓝牙

Android 12+ 蓝牙权限变化：

- `BLUETOOTH_SCAN`
- `BLUETOOTH_CONNECT`
- `BLUETOOTH_ADVERTISE`

典型问题：

- 扫描不到设备。
- 连接断开。
- 权限已给但定位开关关闭。
- 厂商后台限制导致断连。

蓝牙业务要设计断线重连、超时、状态机和日志。

## 9. 音视频播放

推荐 Media3：

```kotlin
val player = ExoPlayer.Builder(context).build()
player.setMediaItem(MediaItem.fromUri(url))
player.prepare()
player.play()
```

Compose 中记得释放：

```kotlin
DisposableEffect(Unit) {
    onDispose { player.release() }
}
```

问题排查：

- 有声无画：Surface/TextureView、解码器、DRM。
- 卡顿：网络缓存、码率、硬解。
- 后台播放：MediaSession、前台服务。

## 10. 下载上传

下载大文件：

- 前台可见短下载：协程 + OkHttp。
- 后台可靠下载：WorkManager 或 DownloadManager。
- 用户可感知长任务：前台服务。

上传要支持：

- 断点续传。
- 重试。
- 网络约束。
- 进度通知。
- 取消。

## 11. 适配专题

需要长期关注：

- 深色模式。
- 多语言。
- 字体缩放。
- 无障碍。
- 横竖屏。
- 平板、折叠屏。
- 多窗口。

这些不是最后美化，而是会影响真实用户能不能正常使用。
