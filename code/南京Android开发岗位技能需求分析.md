# 南京 Android 开发岗位技能需求分析

> **数据来源**：智联招聘 / BOSS直聘 / 猎聘 / 全职招聘网 / 企查查 / 谈职 / 爱企查 等公开招聘信息
> **抓取时间**：2026-10-12
> **样本量**：26+ 个南京在招岗位，覆盖车机座舱、Framework、通用 App、音视频、跨端鸿蒙、应届六大类

---

## 前置：本文的读者定位

本文针对的是一位**12 年开发经验、近 9 年在博泰车联网（Pateo）从事车机开发**的资深工程师。

这个定位决定了本文的写法与普通"求职调研"不同：

- **不做基础扫盲**。T0 层（Kotlin/Java、四大组件、Jetpack）只做清单核对，不展开原理——这些是 12 年经验者天然具备的东西。
- **重点在"薪资天花板在哪里"以及"我离它差什么"**。因此第四节的雇主分类、第六节的定位与议价，才是本文真正的落点。
- **匹配度评估按资深车机工程师口径做**，而不是按转行者口径。9 年车机量产经验在南京市场是稀缺筹码，很多 JD 里写的"有车载产品工作经验优先"，对你而言是直接加分项而非勉强够。

一句话概括南京市场的机会结构：**你所在的赛道（车机）恰好是南京最强、薪资最高的赛道；剩下的问题只是"投谁"和"价格怎么谈"。**

## 一、先说结论

1. **岗位结构是"车载座舱 + Framework 系统 + 通信/嵌入式 + 音视频"四足鼎立**，纯粹的互联网 App 岗数量偏少，且薪资普遍压在 7K–20K 区间。
2. **硬门槛高度收敛**：Java/Kotlin + 四大组件 + Jetpack + 架构模式 + 网络存储 + 性能优化，这 6 项几乎是 100% 重叠，不满足基本进不了面。
3. **薪资天花板由"离系统层有多近"决定**：App 层 7–20K → 车机/Framework/HAL 层 15–45K → 音视频/系统底层 20–60K。同样写 Kotlin，懂不懂 Binder、能不能改 AOSP，价格差一倍以上。
4. **南京存在"一线薪资"的入口，但集中在少数几家自研主体**。小米南京（建邺·小米南京科技园）车机 Android 岗给到 **20–50K·14–16 薪**；光庭信息车机 FW/HAL 给到 **18–45K·13 薪**。这两类是本地车机人最值得认真准备的目标。

## 三、技能要求：分成四层看

### T0 硬门槛（几乎每一条 JD 都会写）

| 技能 | 具体要求 | 出现频率 |
|---|---|---|
| **Kotlin** | 已是绝对主力语言；协程、扩展函数、高阶函数、Flow 明确被写进要求 | 极高 |
| **Java** | 仍在大量 JD 中与 Kotlin 并列；Framework / 车机岗 Java 更是必选项 | 极高 |
| **Android 四大组件与生命周期** | Activity/Fragment 生命周期、启动模式、数据传递、独立完成模块 | 极高 |
| **Jetpack 组件** | ViewModel、LiveData 为基线；Room、Navigation、WorkManager、DataStore 逐步成为标配 | 高 |
| **Jetpack Compose** | 明确出现在多个 JD 中（含"跟踪 Compose 等新框架"的表述），已从加分转为要求 | 中→高 |
| **网络通信** | Retrofit + OkHttp 标配；HTTP / TCP-IP / Socket 协议列为硬性要求 | 极高 |
| **数据存储** | Room / SQLite 实际使用经验 | 高 |
| **Git + Android Studio** | 明确列出，含 Code Review、分支管理、上库流程 | 极高 |
| **多线程 / Handler 机制** | 多线程编程、线程池、Handler/Looper 消息机制 | 极高 |

### T1 主流要求（中高级岗高频出现）

- **架构模式**：MVVM 是事实标准，**MVI 与 MVP 被并列列出**；组件化 / 模块化 / 插件化 / 工程化建设
- **性能优化**：启动速度、渲染流畅度、内存泄漏、卡顿、耗电、网络性能；工具链 **Android Profiler、LeakCanary、Systrace、Perfetto**
- **稳定性治理**：ANR、Java Crash、Native Crash、Watchdog、系统死机重启的定位与闭环
- **第三方 SDK 集成**：地图 / 定位 / 导航 / 推送 / 支付（南京车机岗对"定位导航地图"尤其看重）
- **WebView + H5 混合开发**：JavaScript 接口调用、Native ↔ JS 双向通信、内嵌 H5 页面优化
- **跨端框架**：Flutter / React Native / uni-app / Weex，多数写"了解原理即可，有集成经验优先"，但 **RN 容器的加载性能与稳定性优化**被单独列为职责
- **设计模式与数据结构**：面向对象、常用设计模式、算法基础
- **隐私合规与应用市场发布**：国内外各大应用市场上架、合规 / 安全法规 / 隐私合规问题处理

### T2 差异化技能（决定薪资档位，南京特色极强）

| 方向 | 具体技能 | 对应薪资档 |
|---|---|---|
| **Framework 系统层** | AMS / WMS / PMS / Input / PowerManager / Storage / Sensor / SurfaceFlinger / Audio / WiFi / Bluetooth / SystemUI；systemui、keyguard、Settings 模块维护 | 20K–60K |
| **IPC 与 HAL** | Binder、AIDL、HIDL；系统服务运行机制 | 20K–45K |
| **AOSP 定制** | AOSP 编译 / 裁剪 / 定制流程、构建系统镜像、构建流程自动化、ROM 适配（高通 / MTK）、BSP | 20K–45K |
| **C / C++ / NDK / JNI** | 与 Java/Kotlin 并列的硬要求 | 20K+ |
| **车机 / 智能座舱** | Android **Car Service**、**VHAL / VehicleHAL**；**CAN / SOMEIP / DDS** 车载信号对接；仪表投屏、多窗口 / 分屏；车控、车载音频、相机、网络、车载诊断 | 15K–45K |
| **音视频多媒体** | MediaCodec / MediaExtractor / Stagefright / NuPlayer；AudioService / AudioFlinger / AudioPolicy / AudioEffect / SoundTrigger；**ExoPlayer / FFmpeg / GStreamer / VLC**；OpenGL；H.264 / H.265 / AAC；RTP / RTCP / RTSP / RTMP / SRT / WebRTC | 15K–40K |
| **图形渲染** | OpenGL ES / Vulkan / Skia / Shader、图形动效、独立渲染引擎 | 20K–45K |
| **硬件与外设对接** | 蓝牙、串口、传感器、健康数据、北斗设备、手表设备 | 12K–20K |
| **鸿蒙 HarmonyOS** | ArkTS / DevEco Studio、Stage 模型、Ability / UIAbility 生命周期、分布式能力 | 9K–25K |
| **车载底层** | AUTOSAR、MCU / SWC / CDD、CAN / UDS / NM / DoIP、Vector DaVinci / ETAS / EB | 20K–40K |

## 四、按岗位方向与雇主类型拆解

南京的车机相关岗位，按**雇主性质**分成四个圈层，报价与工作方式差别极大。这个分类比"按技术方向分类"更能指导投递。

### 1️⃣ 车机 / 智能座舱

#### 1.1 主机厂 / 自研主体系（报价最高，门槛最实）

**小米南京**（建邺区·小米南京科技园）：

| 岗位 | 经验 | 核心要求 | 薪资参考 |
|---|---|---|---|
| 车机 Android 研发工程师 / android 高级工程师 | 3–8 年 | 小米汽车移动端应用：座舱车机**桌面车模、多媒体、导航、车控、舒控、安防、场景空间**、基础应用（电话 / 天气）；需求理解 + 软件架构与模块设计；Java / Kotlin + 大中型应用架构设计能力 | 20–50K·14–16 薪 |
| 座舱互联应用工程师（A217852） | 5 年+ | **IoT 设备或智能座舱软件开发经验**（Automotive 经验优先）；Java 或 Kotlin + 设计模式 / 数据结构 / 算法；**应用性能与稳定性优化** | 20–50K |
| 座舱软件开发工程师 | — | 座舱车机**系统优化（性能 / 稳定性）**、量化标准、大数据与工具开发、长效机制建设 | — |
| Android 图形渲染工程师 | 应届可投 | 座舱系统**图形动效**开发与升级优化；**座舱独立渲染引擎**研发；**OpenGL ES / Vulkan / Skia / Shader**；Unity / UE / Cocos 优先 | — |
| Android 开发（南京研发中心） | 5 年+ | MIUI 互联网应用、虚拟运营商业务、全球上网等客户端研发 | 20–50K·14–16 薪 |
| 小米汽车-MCU 高级开发工程师 | 5–10 年 | 智能座舱 MCU 软件架构与 SWC 组件开发、基础软件配置集成、AUTOSAR（Vector DaVinci / ETAS / EB）、**CAN / UDS / NM / DoIP** | 20–40K·15 薪 |

关于小米，有三个值得注意的判断：

- **它的 Android 岗是"应用层门槛、系统层价格"。** 不要求改 AOSP，只要求 3–8 年移动端应用经验 + 架构设计能力，但要求你懂座舱里车控 / 舒控 / 安防这些跨域信号怎么流到应用层。
- **"性能与稳定性优化"在小米是独立职能**，不是附带要求——座舱软件开发工程师整条 JD 只写性能 / 稳定性 + 量化标准 + 工具 + 长效机制。
- **工作时间公示为 9:30–21:30**（HR 称可保证双休）。高薪的代价与一线城市一致。

#### 1.2 汽车软件方案商 / Tier1 系

- **光庭信息**（18–45K·13 薪·江宁）：AOSP 编译 / 裁剪 / 定制、Framework 层 + HAL 层（HIDL/AIDL）、Binder、车控 CarService/VehicleHAL、车载音频、相机、网络、诊断；要求 Linux 基础命令与系统调试工具。**JD 原文明确写"不限制细分模块（车控、音频、相机、网络、诊断、AOSP 定制均可），只要有智能座舱车载系统 FW/HAL 量产开发经验即可投递"**——这是南京对车机 FW/HAL 经验最直接的变现口子。
- **颖派科技**：AOSP 框架层组件与 HAL 开发、**Window Manager 定制**、构建系统镜像、构建流程自动化、**系统启动时间优化**、Launcher。
- **华苏科技**（10–25K）：**深度定制 AMS/WMS/PMS**，支持多窗口 / 分屏；系统级性能优化、ANR / 死机；**ROM 对高通 / MTK 平台适配与驱动整合**；Systrace/Perfetto；中间件 Service（多媒体、时间同步、诊断、CarService、仪表投屏）。

#### 1.3 人力服务 / 驻场系（门槛略低，出差驻场是常态）

- **软通动力**（12–15K，接受大专）：Java/Kotlin 基础 + Android 框架特性（跨进程通信、Handler）+ OOP / 数据结构 / 设计模式 + MVC/MVP/MVVM；车机项目经验优先。
- **润和软件**（13–26K·江宁，座舱）：Android 平台车机应用设计与**移植**、**嵌入式开发经验**、Android 系统应用开发流程。
- **经创集团**（10–18K·雨花台，蓝牙电话方向）：负责 **Android Car Service、VHAL** 模块开发；对接 **CAN、SOMEIP、DDS** 车载信号；四大组件 + **AIDL 跨进程通信**；系统稳定性问题排查——**ANR、JavaCrash、NativeCrash、Watchdog、内存泄漏、系统死机重启**。加分项：智能座舱 / 仪表 / 中控**量产项目**、**Framework 底层源码调试**、车载日志抓取与性能优化。

> 📌 1.3 系报价低但岗位多，对 12 年经验者性价比不高；其中**经创集团那条 JD 的知识密度最高**（CarService + VHAL + CAN/SOMEIP/DDS + 稳定性治理），适合作为"知识缺口自检清单"来用。

### 2️⃣ Framework / 系统层（南京的"隐形高薪池"）

**代表企业**：机器岛智能科技、颖派科技、BOSS直聘（南京研发）、紫光展锐

- **机器岛智能科技**（30–60K，智能音箱）：熟悉 Java/C/C++；熟悉**以下一个或多个模块——AMS、PMS、WMS、Input、SurfaceFlinger、Audio、WiFi、Bluetooth、SystemUI**；能解决 UI 卡顿、应用 crash 和 ANR；有 **BSP 开发经验**优先。
- **BOSS直聘南京**（5–10 年）：C/C++ 与 Java 至少精通一门 + Linux + Framework 核心服务 + 死机重启 / ANR / FC + **graphic 系统、hwui、wms**；游戏图形处理经验优先；**有 AOSP/GitHub 开源贡献者优先**。
- **高级客户端 / 操作系统 / Framework 研发**（3–5 年）：C++ 和 Java/Kotlin 双修 + 操作系统原理 / 数据结构 / 算法 + 大规模应用架构设计 + 冷启动优化 + Compose。
- **Framework 岗通用要求**：systemui / keyguard / Settings 模块维护；WMS/AMS/PMS/PowerManager/Storage/Sensor；C/C++/Java/Python/Shell 至少一门。

> 📌 这一类 JD 高频出现的词是"**独立定位**""**源码级定制**""**量产**"——本质是在筛"能不能一个人在陌生系统里定位问题"。

### 3️⃣ 音视频 / 多媒体（技术壁垒最厚）

**代表企业**：紫光展锐、软通动力、北弓智能、汉桑科技

- **紫光展锐**（20–40K·浦口，音频框架）：Android 多媒体系统框架（**MediaPlayer / MediaRecorder / MediaCodec / MediaExtractor / Stagefright / NuPlayer**）+ Android 音频系统框架（**AudioService / AudioEffect / AudioPolicy / AudioFlinger / SoundTrigger**）；gstreamer / ffmpeg / vlc 加分；处理通话、录音、播放、音效、音质、编解码、**Google XTS** 各类问题。
- **软通动力**（15–27K）：**Demuxer / Decoder / Render**；ExoPlayer / FFmpeg / GStreamer；**OpenGL** 滤镜与后处理特效；视频播放器需求开发与维护。
- **北弓智能**（建邺）：**JNI 开发** + Linux C/C++ + **RTP/RTCP、RTSP、RTMP、SRT** 传输协议 + H.264/H.265/AAC 编解码 + TCP/IP、Socket、UDP/TCP 长连接与消息可靠投递（面向党政军自主可控终端）。
- **汉桑科技**（7–12K·14 薪，智慧音频）：大前端（Android/iOS/Flutter/Web 任选）+ HTTP/WebSocket + C/C++ 优先。

> 📌 音视频岗在南京有个鲜明特征：**都要 C/C++ 甚至更底层的理解**，Kotlin 只是外壳。护城河最深，也最不容易被替代。**车机与音视频在"媒体播放链路"上是重叠的**——车机的多媒体应用、蓝牙音乐、投屏，本质上都在这一栈上。

### 4️⃣ 通用 App 开发（占比中等，薪资偏低）

**代表企业**：苏宁易购、焦点科技（中国制造网）、浩鲸科技、万声音乐、中瑞集团、上海之几

- **中瑞集团**（15–20K·13 薪·浦口）：*"熟练掌握 Java、Kotlin…深入理解系统架构、内存管理、网络、多线程、数据库"*；特色是**外设对接**——健康运动、手表、串口、蓝牙、北斗；**Bridge 能力建设**——相机、地图、定位、导航、网络；以及 **RN 容器加载性能优化**。
- **上海之几**（7–9K·雨花台）：Kotlin 精通（协程、扩展函数）+ Activity/Fragment 生命周期 + Jetpack Compose/ViewModel/LiveData + WebView 双向通信 + Retrofit/OkHttp + Room/SQLite + 跨平台框架 + iOS(Swift) 加分 + **需提供 GitHub/App 链接**。
- **浩鲸科技**（15–20K，4 年+·雨花台）：架构设计 + 组件化 / 模块化 / 工程化 + 性能优化（启动速度、内存泄漏、卡顿、耗电）+ **MVVM/MVI** + 组件化 / 插件化 + 安全机制与多机型适配。
- **焦点科技**（20–30K·浦口）：Kotlin 协程等高阶用法 + Jetpack + Retrofit/OkHttp/**Glide** + MVC/MVVM + 模块化 + Android Profiler/**LeakCanary** + 应用市场发布 + **隐私合规**。
- **万声音乐**（15–30K·雨花台，VIVO 音乐）：Android UI 组件、图像动画、数据库、多线程 + **Jetpack 全模块** + MVVM + Kotlin；**音频和直播经验优先**。
- **华设设计集团**（13–20K·雨花台软件谷）：Java/Kotlin + **Android SDK/NDK** + **MVP/MVVM/MVI** + 跨进程通信 + TCP/HTTP/Socket + 端云交互 + 架构搭建经验。

> 📌 这类岗位天花板在 20–30K。对 12 年经验者而言，除非是**万声音乐这种有音频 / 直播诉求的岗**（可与车机多媒体经验衔接），否则不建议作为主攻方向。

### 5️⃣ 跨端与鸿蒙（新兴增量）

- **跨端**：Flutter / React Native / uni-app / Weex 在南京多为加分项；但 **RN 容器的加载性能与稳定性优化**被中瑞集团单列为岗位职责，说明"能用"和"能优化"是两个价格。
- **鸿蒙**：软通动力（9–12K / 11–15K）、鱼跃医疗（15–25K·14 薪·玄武）、深圳易宝（12–20K）。要求集中在 **ArkTS / DevEco Studio / Stage 模型 / Ability & UIAbility 生命周期 / 分布式能力**，且普遍要求"**有 Android 原生经验，能快速迁移改造已有应用**"。**对车机人而言这条路径价值有限**：车载鸿蒙（鸿蒙座舱）目前岗位量还没起来，且车机鸿蒙的技术栈重心在系统集成而非 UI。

### 6️⃣ 应届 / 初级（作为市场基准参照）

- 润和软件 2026 校招（7–11K）：Java 或 Kotlin + 熟悉 C/C++、良好编程习惯；"上架过自己开发的 app 或在 gitee/github 有开源项目"优先。
- 熊猫通信（15–20K，硕士应届）：Java 基础 + Android 系统架构与 API + **配合底层团队完成 Framework 功能扩展** + Android Studio 调试手段。
- 汉桑科技（7–12K·14 薪）：满足 Android(iOS/Flutter/Web) 任一技术栈即可 + HTTP/WebSocket。

> 📌 值得注意的一个对照：**南京硕士应届生的车机相关岗已经报到 15–20K**。这从侧面说明——如果没有系统层能力加持，12 年经验的溢价空间其实被压缩得很厉害。**经验溢价必须通过"系统层 + 量产 + 稳定性治理"这三样来兑现。**

## 五、南京市场的三个结构性特征

**① 岗位高度向"车"和"系统"收敛。**

这与南京的产业结构直接对应：中兴系（润和、浩鲸 / 中兴软创）、华为系人力服务（软通动力）、**小米南京（建邺·小米南京科技园，车机应用 + 图形渲染 + MCU，本地薪资天花板）**、紫光展锐、光庭信息、汽车电子方案商（经创、颖派、华苏），构成了主体需求方。互联网 App 岗集中在苏宁、焦点科技、万声音乐几家，数量有限。

**② 门槛两极分化，中间层"薄"。**

数据能佐证：经验需求中 3–5 年占 45.5%，5–10 年只占 5.5%。市场在大量招"中级士兵"，而"高级架构 / 系统专家"的坑位少但单价极高（30K–60K）。**这个结构对 12 年经验者是有利的**——坑位少意味着竞争面窄，而报价高意味着经验能被定价；但前提是你的能力标签必须落在"系统层"这一侧，而不是停留在应用层。

**③ 学历门槛在车机 / 人力服务赛道明显放松，在 Framework / 音视频赛道收紧。**

软通动力、润和软件、经创集团等明确接受**大专**；而 Framework 与音视频岗普遍要求统招本科甚至硕士。学历在这里是用"技术深度"换的。

## 六、定位与策略（按 12 年车机背景）

### 6.1 你手里的四张牌

| 筹码 | 对应 JD 原文 | 价值判断 |
|---|---|---|
| **9 年车机量产经验** | "有车载产品工作经验优先""有智能座舱量产项目经验者优先" | ⭐⭐⭐ 南京最难被替代的标签 |
| **平台签名系统应用（priv-app，`sharedUserId=android.uid.system`）** | "熟悉 Android 系统应用开发流程""系统应用定制与维护" | ⭐⭐⭐ 大量应用层候选人拿不出这个 |
| **WebView + JSBridge 混合架构（HtmlScreen / HtmlFragment）** | "实现 WebView 与 H5 页面的混合开发及交互""JS 与 Native 双向通信" | ⭐⭐ 高频要求，且你是有架构级实践而不只是用过 |
| **车机 SDK 集成（`hyundai.com.pateo.sdk.vehicle.carservice`）** | "负责 Android Car Service 模块开发""AIDL 跨进程通信" | ⭐⭐⭐ 是切进 Framework 岗的天然跳板 |

### 6.2 会被追问的点，以及怎么准备

以下五点不是"能力缺口"，而是**12 年经验者一定会被深挖的边界问题**。答不上来，前面的经验会被打折；答得上来，直接进入 FW/HAL 档位。

| 追问点 | 面试官真正想听的 | 准备方向 |
|---|---|---|
| **CarService 与 VHAL 的边界** | 你平时是**调** CarPropertyManager，还是理解它下面 `CarPropertyService → VehicleHal → HIDL/AIDL → HAL 进程` 的完整链路？ | 把 CarService 的属性订阅 / 回调链路完整讲一遍，含 `subscribePropertyEvents`、`CarPropertyEventCallback`、`onPropertyEvent` 的跨进程与权限检查 |
| **VHAL 属性系统** | `VehiclePropertyIds`、`AreaId`、`propConfig`、采样率（`SAMPLE_CONTINUOUS` / `ON_CHANGE`）、`getProperty` vs `subscribe` | 讲清"为什么频繁变化的车速要用 ON_CHANGE 而不是轮询"，以及属性配置在 `config` 层怎么定义 |
| **车载信号到底怎么进 Android** | CAN 报文 → （网关 / MCU）→ **SOMEIP 或 DDS** → VHAL → CarService → App 这条链上，每一跳是谁做的 | 这一点你日常大概率只接触最后一跳。**不需要假装做过中间层**，但要把链路讲清楚，并说明你理解边界在哪 |
| **AOSP 编译与定制闭环** | 能不能跑通 repo sync → lunch → mka → 烧写 → 验证，以及改过哪些模块 | 哪怕只是把一个 systemui 或 Settings 模块改完走通一次完整闭环，你讲"做过"和讲"了解"是两个价格 |
| **稳定性问题的定位方法论** | ANR / NatvieCrash / Watchdog / 死机重启分别在哪一层抓、用什么工具、怎么下结论 | 准备 2–3 个你自己真实定位过的疑难问题（车机的黑屏 / 重启 / 卡顿都可以），要有"现象 → 抓取方式 → 定位结论 → 修复验证"的完整叙事 |

### 6.3 目标分层

| 档位 | 目标 | 预期报价 |
|---|---|---|
| **A 档（主攻）** | 小米南京·车机 Android 研发 / 座舱互联应用；光庭信息车机 FW/HAL | 25–45K |
| **B 档（备选）** | 颖派科技（WMS 定制 / 构建镜像）、华苏科技（AMS/WMS/PMS 定制 + 平台适配） | 20–30K |
| **C 档（不建议主投）** | 软通动力 / 润和 / 经创的人力服务岗；通用 App 岗 | 12–20K |

**为什么不建议主投 C 档**：三个理由。第一，报价覆盖不了 12 年经验的溢价，进去之后议价空间被封死；第二，人力服务型岗位的成长来自"换项目"而不是"深技术"，9 年车机积累会被摊薄；第三，润和软件那条座舱 JD 已经报到 13–26K，与 A 档下限重叠，说明"低门槛"在南京并不等于"低竞争"。

### 6.4 议价锚点

- **用年包而不是月薪谈**。小米是 14–16 薪、光庭是 13 薪，月薪相同的情况下年包可能差 15%–25%。谈判时先把"×13 / ×14 / ×15"问清楚。
- **用"量产"和"稳定性"作为溢价理由**。南京 JD 里反复出现"量产项目经验""独立定位 ANR / 死机 / 重启"，这正是 9 年车机经验最直接的兑现方式。
- **用 CarService / VHAL 这条线锚定 FW/HAL 档，而不是应用层档**。南京的应用层岗位天花板明确（20–30K），而 FW/HAL 档下限就是 18K、上限 45K。同一个人的同一年经验，挂在哪个标签下，价格完全不同。

### 6.5 补齐顺序（如果要做准备）

1. **VHAL / VehicleHAL 与 CarService 的分层边界** —— 你已有 CarService SDK 侧经验，往下一层理解 HAL 边界，投入产出比最高。
2. **AOSP 完整编译 + 一次真实定制** —— 把"了解"变成"做过"，这是从 B 档跨到 A 档的关键一跳。
3. **Binder / AIDL 源码级** —— 是 AMS / WMS / CarService 共同的底座，一次投入长期复用。
4. **CAN / SOMEIP / DDS 与 UDS / DoIP** —— 纯协议知识，面试前集中突击即可，不必提前长期投入。
5. **Systrace / Perfetto 的实战叙事** —— 把过去的优化经验整理成可复述的量化故事。
