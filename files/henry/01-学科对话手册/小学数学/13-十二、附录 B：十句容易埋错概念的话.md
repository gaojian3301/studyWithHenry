# 十二、附录 B：十句容易埋错概念的话

这几句都是家长好心教的，但会把孩子带偏。列在这里，供自查。

| 别这么说 | 问题在哪 | 可以这么说 |
|---|---|---|
| "3 个 4 就是 3×4" | 和新教材约定相反（应为 4×3） | "相同加数写前面，个数写后面" |
| "0 不能做除数，这是规定" | 会让孩子以为是人为约定 | "12 个糖分给 0 个人，你是分不出来的" |
| "乘法就是变大" | 乘 0.5 会变小 | "乘法是'几份这样的数'" |
| "除法就是变小" | 除以 0.5 会变大 | "除法是看里面有几个这样的数" |
| "分子大分数就大" | 1/2 < 2/3 但 3/8 > 1/4 的情况会混乱 | "要看清是几份里的几份" |
| "面积大周长就大" | 长条和方块可以面积相同周长差很多 | "这是两件事，分开算" |
| "负数就是欠钱" | 温度、楼层、海拔都不是欠钱 | "负数是往相反方向走" |
| "约等于就是四舍五入" | 估算的目的是好算，不是精确 | "我们只要知道大概范围" |
| "A 比 B 多 3 倍" | 中文有歧义，有人理解为 3B，有人理解为 4B | 一律说"A 是 B 的 4 倍" |
| "小数点后面加 0 没影响" | 数值相等，但 23.5 和 23.50 的精度不同 | "大小一样，但说的是精度不一样" |
