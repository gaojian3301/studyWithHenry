# 十三、附录 C：十个在家就能做的观察

> 原《生物》手册 · 第 14 章（共 16 章）。
> **导航**：[← 上一章：十二、附录 B：十四句容易讲错的话](<13-十二、附录 B：十四句容易讲错的话.md>) ｜ [本册目录](<00-开篇与用法.md>) ｜ [下一章：十四、附录 D：一周七句 →](<15-十四、附录 D：一周七句.md>)

| 活动 | 怎么做 | 看什么 |
|---|---|---|
| **绿豆发芽** | 湿棉花 + 绿豆，每天拍照 | 胚根先出还是胚芽先出 |
| **洋葱表皮** | 撕内膜，手机微距镜头看 | 细胞壁的格子 |
| **芹菜染色** | 芹菜插在红墨水里 | 导管在哪儿 |
| **叶子遮光** | 叶片上贴黑纸，一天后摘下来 | 见光部分才是绿的 |
| **阳台向光性** | 豆苗放窗边，一周转一次盆 | 茎往哪边长 |
| **面包发霉** | 一片湿润面包放袋里 | 霉菌怎么扩散 |
| **酵母吹气球** | 酵母 + 糖 + 温水装瓶，套气球 | 呼吸产生气体 |
| **测脉搏** | 静坐、跑完各测一次 | 心率变化 |
| **厨房微生物** | 洗手前后按手印在琼脂上（或用面包） | 菌落数量 |
| **小区物种清单** | 一周内记录见到的鸟、虫、树 | 多样性 |
