# 十二、附录 B：十四句容易讲错的话

> 原《生物》手册 · 第 13 章（共 16 章）。
> **导航**：[← 上一章：十一、附录 A：分年级索引](<12-十一、附录 A：分年级索引.md>) ｜ [本册目录](<00-开篇与用法.md>) ｜ [下一章：十三、附录 C：十个在家就能做的观察 →](<14-十三、附录 C：十个在家就能做的观察.md>)

| 常说的话 | 问题在哪 | 换成这样说 |
|---|---|---|
| "人是从猴子变的" | 人和现代猴子有共同祖先，不是谁变谁 | "人和猴子有同一个祖先，后来分成了两支" |
| "用进废退" | 拉马克的观点，已被否定。练肌肉不会遗传给孩子 | "练出来的本事不会写进基因里" |
| "进化就是越来越高级" | 进化没有方向，只有"更适应当前环境" | "进化是变得更适应，不是变得更好" |
| "适者生存就是强者生存" | "适"是适应环境，不是强壮。蟑螂比老虎成功 | "能适应环境的活下来，不是最强的活下来" |
| "基因决定一切" | 环境决定基因开不开、开多少 | "基因是图纸，环境决定怎么用这张图纸" |
| "血是蓝色的" | 静脉看起来发青是皮肤对红光的吸收，血本身是暗红 | "血是红的，青筋是皮肤透出来的颜色" |
| "人脑只用了 10%" | 完全没有依据的谣言，成像显示大部分脑区都在活动 | "大脑几乎一直在用，只是不同时候用不同区域" |
| "抗生素治感冒" | 感冒多为病毒，抗生素无靶可打 | "抗生素只杀细菌，感冒是病毒" |
| "发烧要赶紧退" | 适度发烧是免疫反应，高热才需要处理 | "发烧是身体在打仗，太高了才需要帮忙" |
| "秋天叶子变黄是染上的" | 黄色本来就在，是叶绿素分解后露出来的 | "叶子本来就是黄的，绿色退掉了才看见" |
| "年轮一年一圈" | 热带不明显，有的树一年两圈 | "年轮大多一年一圈，但不绝对" |
| "鲸鱼是鱼" | 哺乳动物，用肺呼吸、胎生、恒温 | "鲸是哺乳动物，只是住在水里" |
| "植物只光合作用不呼吸" | 植物日夜都呼吸，白天光合大于呼吸 | "植物也呼吸，只是白天做的光合更多" |
| "转基因都是坏的" | 这是一项技术，好坏看具体改什么、怎么评估 | "转基因是一项技术，要一个一个问题看" |
