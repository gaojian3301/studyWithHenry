# 十二、附录 A：追问句式库

这一节是全文最该记住的部分。**逻辑训练不靠讲，靠问。** 但"问什么"有讲究。

| 想让他做到 | 就这么问 |
|---|---|
| 给出证据 | "你怎么知道的？" / "你看见的，还是听说的？" |
| 找反例 | "有没有可能不是这样？" / "能想出一个例外吗？" |
| 找替代解释 | "还有别的原因吗？" / "除了这个解释，还能怎么解释？" |
| 校准范围 | "是所有的，还是有一些？" / "一直这样，还是就这一次？" |
| 说清概念 | "你说的这个词，具体指什么？" |
| 区分事实与猜测 | "这是发生的事，还是你的想法？" |
| 往前推一步 | "如果真是这样，那会怎样？" / "然后呢？" |
| 检查一致性 | "你刚才说的和现在说的，是一回事吗？" |
| 检验自己 | "如果我说你错了，你会怎么反驳我？" |

最后一句特别好用：**让孩子站到对面去，替反方说话**。他如果能替对方把理由说圆，说明他真的懂了；说不圆，说明他只有立场，没有理由。
